# Swaroop Wayadande | Portfolio

A modern personal portfolio website built with React, TypeScript, Vite, Tailwind CSS, and shadcn-style UI patterns. The site presents my work as a Computer Science graduate focused on application security, web testing, and full-stack development.

## Overview

This portfolio highlights:

- My background in application security and web testing
- Selected projects and practice work
- Core skills and learning areas
- Professional experience and certifications-style context
- Contact links and resume access

It is designed to feel clean, professional, and technically polished while remaining lightweight and fast to load.

## Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js 18+
- npm or bun

### Install dependencies

```bash
npm install
```

### Run the development server

```bash
npm run dev
```

Then open the local URL shown in the terminal, typically:

```bash
http://localhost:5173/
```

### Build for production

```bash
npm run build
```

### Preview production build locally

```bash
npm run preview
```

## Scripts

```bash
npm run dev       # Start Vite dev server
npm run build     # Create optimized production build
npm run preview   # Preview the production build
npm run lint      # Run ESLint checks
```

## Customization

To personalize the portfolio:

- Update the personal details and intro text in `src/App.tsx`
- Replace project data and descriptions in the project array
- Update resume URL and social links
- Replace screenshots in `src/images/` or `public/`
- Adjust theme colors and layout in `src/App.css` or Tailwind configuration
